# GameForKeyEditor（PatternDIY 4K 谱面解析器）项目树与逻辑表

> 基于 Unity 2018.4.2f1（Mono 后端）打包的音游谱面编辑/转换器。
> 分析对象：`D:\MusicScoreConvter\`，程序集证据来自 `Assembly-CSharp.dll` 反射与反编译。

## 三、启动与数据流逻辑表

| 步骤 | 链路 | 说明 |
|---|---|---|
| 1 启动 | exe → UnityPlayer → Mono → level0 场景 → MainPanelViewer.Awake | Configs.LoadConfig 读 configs\config.ini |
| 2 建谱 | 选 mp3（拷入 musics\）→ BpmAnalyzer.exe 出 BPM → CreateFile | cellCount=round(时长/(60/BPM)+1)，Init 建 30 屏格阵列 |
| 3 编辑 | 点击格 → gridTime=T(index) 吸附 → AddSingleKey/AddMultiKey | 每次操作先 Record 全表快照（撤销栈） |
| 4 拖拽 | SetMoveObj → UpdateMove 跟手 → ApplyMoveKeys 按落点格重算 KeyTime | MULTI_KEY 整组平移并新建 nodeGroupId |
| 5 试玩 | StartGame → 按滚动比例反推 playPosition → 音频起播 → UpdateKeyVisible 剔屏外键 | isAutoHit 自动击打校验谱面可行性 |
| 6 备份 | 每 360s → back_up\<日期>\<曲名>_H_M.mmg | mmg 二进制：魔数 100000 + float BPM + 名称串 + 定长记录 |
| 7 存盘 | Mst.toBuffer → Mmg/Json/Imd 格式写出 | JSON 走 BNDQ 模板（tracks 3~6） |
| 8 发布 | sample 命名规范（曲名_ez/hd/ms.mmg + cover.png）→ COSXML 上传 | DifficultData 多难度打包，PostMusicscoreUtil 表单直传 |
| 9 转换 | Imd/Mmg/Json 任一输入 → Mst 枢纽 → 目标格式 | FileInfo.suffixMde/Dynamix/Musync 路由到外部音游格式 |

## 四、关键公式速查（编辑轴层）

| 名称 | 公式 |
|---|---|
| 单格时长 | elementTime = 60 / BPM / G（G∈{1,2,3,4,6,8,9,12,16}） |
| 格→时间 | T(index) = 60/BPM/G × index + timeOffset/1000 |
| 格子高度 | cell_h = round(CellSizes[sizeIndex] / G)，CellSizes=368→48 |
| 键→面板像素 | y = −(H_total − (KeyTime/elementTime × cell_h + cell_h))；x = node_wigth + 85×Track |
| 鼠标→格 | index = floor(H_total×(1 − y_world/H_total)/elementTime)；track = floor((mouseX−640−node_wigth)/85) |
| 判定线 | _timeLineStartPos = 760×0.8 = 608 px |
| 试玩滚屏 | y_game = 536 × (GameKeyTime − gameTime)/showTimeLength（默认 0.5s，可调） |
| 四时间形态 | ShowTime=−1.5×showTimeLength；HitTime=−0.1s；MissTime=+0.2s（相对 KeyTime） |
| 导出 tick | tick = KeyTime × BPM/60 × bpn（bpn=每拍细分，DataUtils beat/note/time 域，毫秒 v=60000/bpm） |
| 命中容差 | \|Δt\| < 0.0001s，同轨同刻唯一键 |
| 翻轨映射 | {0↔3, 1↔2}（4K 镜像） |
